# RepoIQ frontend

This repository contains the frontend for the RepoIQ application (Vite + React + TypeScript).

## Running locally

Requirements: Node.js and npm (or pnpm/yarn).

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

Build for production:

```sh
npm run build
npm run preview
```

Replace any project-specific deployment steps as needed.
